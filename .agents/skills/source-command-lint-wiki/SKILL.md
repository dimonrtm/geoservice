# /lint-wiki

`/lint-wiki` проверяет техническое и структурное здоровье wiki.

## Шаг 1. Запустить Linter

```powershell
python scripts/lint-wiki.py --root .
```

Проверка ищет:

- отсутствующий frontmatter;
- неполный frontmatter;
- битые wikilinks;
- пустые ноды;
- ноды без `source`, когда источник обязателен.

## Шаг 2. Семантический Обзор

После технической проверки вручную оценить:

- дублирующиеся ноды;
- противоречия между `Vision_wiki` и `Code_wiki`;
- устаревшие решения;
- follow-up'ы без статуса;
- новые RAW inputs без ingest.

## Шаг 3. Что Можно Исправлять Сразу

Без отдельного implementation task можно исправлять только wiki-структуру:

- битые wikilinks;
- опечатки в wikilinks;
- missing frontmatter в wiki-файлах;
- пустые `_info.md`;
- индексы wiki.

Конфликты старой документации с новыми знаниями исправлять только после `/ingest`, только если конфликт уже есть в `Vision_wiki/decisions/followups/index.md` и связан с `Code_wiki`.

## Шаг 4. Отчет

Обновить или подготовить для пользователя:

- сколько найдено проблем;
- что исправлено;
- что требует решения пользователя;
- нужно ли запускать `/ingest` или `/sync-vision`.

## Ограничения

- Не удалять wiki-файлы автоматически.
- Не мержить дубли без подтверждения.
- Не править код, конфигурацию, миграции или тесты.
- Не менять смысл продуктовых решений как часть `/lint-wiki`.
