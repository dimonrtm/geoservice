# Выбор положения устройств и охвата оперативного задания

## Rule

Диспетчер выбирает опубликованные рабочие соединения для проблемного участка и время расчёта. На построенных участках он учитывает границу подтверждённого ввода. Для каждого влияющего на путь устройства использует последнее подтверждённое положение, действовавшее к этому моменту. Поздняя доставка более раннего сообщения пополняет историю. Неустранимое противоречие оставляет положение неизвестным. Срок годности сообщения для всех отраслей исследованием не установлен.

При неизвестном положении и достаточной топологии диспетчер рассчитывает охват для правдоподобных вариантов. В наряд входят ветви, общие всем вариантам, и отдельно дополнительные ветви, попавшие только в некоторые из них. Бригаде указывают устройство для проверки. При иных пробелах, из-за которых сравнить варианты нельзя, охват остаётся неустановленным. [[Wiki/value_objects/calculated_outage_extent|Расчётный охват]].

## Decision Outcome

Получив полевое подтверждение, диспетчер уточняет расчётный охват. Для следующей трассировки подтверждённое переключение можно учесть до публикации постоянной правки. Данные о возврате услуги позволяют закрыть только подтверждённую часть уже выданного задания. [[Wiki/commands/record_service_restoration|Учёт восстановления]].
