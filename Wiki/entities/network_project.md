# Проект ГИС, слой и тип актива

В ER-диаграмме `PROJECT` обозначает проект ГИС, принадлежащий организации. По проекту можно найти опубликованные слои, подготовленные версии сети и задания обмена. Это позволяет различить, с данными какой сети работает редактор и для какого проекта получатель ожидает выгрузку. [Концептуальная диаграмма](../../RAW_inputs/documents/UtilityGisEditor.md#бизнес-модели-и-метрики-успеха).

| Объект | Связь в исходной модели | Для чего она нужна |
| --- | --- | --- |
| Проект ГИС (`PROJECT`) | Принадлежит одной [организации](../actors/organization_and_access.md). Содержит [версии сети](edit_version.md), публикует слои и инициирует [задания обмена](integration_job.md). | Редактор относит правку к версии того проекта, чьи данные обновляет. |
| Слой (`LAYER`) | Относится к проекту и содержит [активы](network_feature.md). | Редактор выбирает набор пространственных данных для работы. Источник предусматривает разграничение доступа к слоям и объектам. |
| Тип актива (`ASSET_TYPE`) | Каждый актив имеет инженерный тип. Один тип может характеризовать несколько активов. | По типу различают, например, трубу и задвижку при заполнении атрибутов и проверке допустимых соединений. Полный справочник для отдельной отрасли ещё предстоит определить. |

Слой отвечает на вопрос, где в составе проекта ведут объект, тип — что это за оборудование. Диаграмма связывает их через конкретный актив. В строительном процессе проектировщик передаёт подрядчику [[Wiki/concepts/design_revision|редакцию чертежа]] с согласованной трассой. Такая передача задаёт основание для сверки построенного участка.
