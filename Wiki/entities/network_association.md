# Узлы и рёбра сети

Узел (`NETWORK_NODE`) представляет место соединения, ребро (`NETWORK_LINK`) связывает узлы. В концептуальной диаграмме для ребра различены начало и конец. Один узел может служить началом или концом нескольких рёбер. Допустимость соединения и направление имеют значение для топологической проверки и трассировки.

Редактор проверяет, какие элементы соединяет изменённый участок. Диспетчер использует эти связи для поиска отключающих устройств и оценки воздействия по сети в обоих направлениях. В источнике отсутствует каталог допустимых соединений по типам оборудования.

[UtilityGisEditor.md · Данные, форматы и интеграции](../../RAW_inputs/documents/UtilityGisEditor.md#данные-форматы-и-интеграции)

Редактор устанавливает общий узел по свидетельству о стыке и обеих трубах. Пока подключение неизвестно, спорное место сохраняется отдельно и переход через него не создаётся. В исходной ER-диаграмме у актива показано возможное представление одним узлом или одним ребром. По решению GeoService после установки задвижки два новых ребра могут представлять одну сохранившуюся физическую трубу. [[Wiki/entities/inspection|Первоначальный осмотр]] по-прежнему относится к этой трубе.
