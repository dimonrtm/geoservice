# Построенный участок участвует в трассировке действующей сети

## Predicate

Для включения опубликованной построенной части в действующую сеть эксплуатация подтвердила ввод именно этого объёма, а его рабочие подключения установлены. В конкретной оперативной трассировке дополнительно учитываются положения устройств на время расчёта.

## Failure Meaning

Труба, принятая по съёмке, может уже быть видна на карте. При неподтверждённой врезке переход через неё отсутствует. Частичный ввод не открывает путь через остальные участки проекта.
