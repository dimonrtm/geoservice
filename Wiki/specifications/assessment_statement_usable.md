# Пригодность утверждения для заявленного использования


## Predicate

Для использования конкретного утверждения одновременно установлены:

1. Однозначные ID/редакция документа, объект и проверенное сохранённое состояние; историчность не скрыта.
2. Цель, участок, свойство, критерий и ограничения соответствуют предполагаемому использованию.
3. Автор/дата выпуска, метод и версии evidence прослеживаемы; вывод воспроизводим в заявленной области либо прямо выражает недостаточность доказательства.
4. Текущая применимость проверена: известные исправления, отзывы и споры разобраны; зависимые сомнительные утверждения не используются как положительные.
5. Частичный результат, непроверенный остаток и независимые измерения качества различимы; нет необоснованного расширения охвата.
6. Выписка/копия сохраняет существенные ограничения и связь с актуальным состоянием редакции.

## Failure Meaning

Нельзя опираться на данное утверждение для указанной цели; это не доказательство ошибочных XY, не отмена факта Save и не автоматический Revert. Пригодное отрицательное заключение можно использовать для решения о коррекции; пригодное сообщение unverified — для запроса недостающих свидетельств. Predicate не означает позиционный pass или разрешение эксплуатационного использования.

## Границы

Это принятая спецификация ручного решения, не реализованный evaluator/guard. Для положительного утверждения о положении отдельно необходим [[Wiki/specifications/saved_line_quality_assessment]] с неизменным критерием. Для смысла правки — [[Wiki/specifications/line_edit_basis_applicable]]. При неизвестном техническом исходе сначала recovery. Не требуется абстрактная гарантия оповещения всех неизвестных получателей, но известное ограничение нельзя скрывать.
