# Редакция проекта применима к построенной части

## Predicate

Для оценки соответствия установлены построенная часть, выданная для её выполнения редакция и применимые утверждённые изменения. Позднее изменение можно использовать для ранее выполненной работы, когда оно явно распространяется на эту часть.

## Failure Meaning

При неясном охвате распоряжения заключение о соответствии остаётся открытым. Измеренную геометрию сохраняют как факт. Уполномоченный источник ретроспективного решения в этом случае остаётся открытой частью NET-11.
