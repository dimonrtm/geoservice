# Состояния Результата Редактирования

Язык из синтезированного исследования принят владельцем проекта; реальным интервью он не является. Основание — ответы 3–5, 8–10, 12–13 источника.

| Термин | Значение | Не означает |
| --- | --- | --- |
| Исходное состояние работы | Неизменяемое основание данной рабочей версии | Самое свежее состояние авторитетной сети |
| Сохранённое состояние | Актуальная геометрия, повторно прочитанная из рабочей версии | Геометрия из любого старого подтверждения |
| Несохранённая правка | Локальное намерение редактора относительно известного состояния | Устойчивое изменение сети |
| Подтверждение сохранения | Результат одного определённого действия | Гарантия отсутствия последующих изменений |
| Результат неизвестен | Редактор не установил судьбу отправленного действия | Ни отказ, ни доказательство ещё работающей серверной операции |
| Текущих правок нет | Текущее состояние совпадает с исходным | Отсутствие истории сохранений или подтверждённое качество |
| Качество не подтверждено | Для соответствующего критерия нет достаточного действительного результата | Ошибка записи или автоматический запрет технического черновика |

Локальное намерение, результат операции, актуальная геометрия и качество — независимые аспекты. «Сохранено в рабочей версии» не заменяет проверку формы, точности, топологии, review или post. No-op предлагается объяснять как отсутствие изменения после учёта точности хранения.

Отмена несохранённой правки возвращает последнее сохранённое состояние; Revert возвращает исходное состояние работы новой операцией. История при Revert не исчезает. См. [[Wiki/policies/editor_recovery_policy]].
