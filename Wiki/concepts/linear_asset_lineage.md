# Происхождение физически преобразованных участков линии

Единицу учёта определяют по границам самостоятельного обслуживания. Чтобы проследить физическое преобразование, для каждого исходного и результирующего участка указывают, какая часть одного участвовала в образовании другого, дату действия и основание. По обеим сторонам сохраняются прежние обозначения. При линейной привязке указывают систему отсчёта и редакцию линии.

- При физическом делении одной единицы на две исходная завершается. Обе новые единицы ссылаются на соответствующие части прежней.
- При физическом объединении двух единиц новая ссылается на обе. Проверенное свойство одного предшественника применимо только в обоснованной области.
- При переоцифровке или обнаружении прежнего неучтённого узла фиксируются редакция и дата получения знания. Для вывода о дате физических работ нужно отдельное свидетельство.
- При локальном ремонте сохраняется история продолжающейся единицы и записывается область работ. Самостоятельно учитываемая вставка имеет собственное происхождение. Если граница неоднозначна, распорядитель сетевых данных устанавливает её по исполнительным сведениям.

Выбор создавать идентичности всех результатов при действительном изменении числа обслуживаемых единиц принят условной организацией по DISC-2026-11-21-02. Временный полевой номер и выбор строки инструментом GIS могут служить ссылками на прежнее представление.
