# Conflicts Catalog

Каталог противоречий, которые мешают построить полную непротиворечивую доменную модель.

В исследовании проверены два похожих случая. Для расчётной модели авторы обследования в Свакопмунде при неизвестном стыке допускали вывод по диаметрам. Для изменения официального графа GeoService требует свидетельства об обеих присоединённых трубах. Отличается назначение модели. Такое расчётное допущение не разрешает редактору создать подтверждённый узел. [NET-04 и свидетельства](../../RAW_inputs/documents/2026-11-27-field-information-answers.md#net-04).

При списанном насосе бухгалтерия устанавливает факт учётной операции, выезд — присутствие конкретного оборудования. Обе записи могут быть верны одновременно. Для участия насоса в работе редактор выясняет характер отключения у эксплуатации.
