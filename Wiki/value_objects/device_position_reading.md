# Сведения о положении устройства

## Meaning

Подтверждение содержит опознанное устройство, сообщённое положение, время его действия и источник. Время получения служит для разбора доставки. При расчёте диспетчер выбирает положение по времени действия. Подтверждения разных устройств нельзя упорядочить как последовательные положения одного устройства.

## Equality

Для учёта одного утверждения значения совпадают, если совпадают устройство, положение, время действия и источник. Два разных источника могут независимо подтвердить одно положение. Разные положения на одно время сохраняются как противоречащие свидетельства, если последовательность установить нельзя.

## Immutability

Позднее полученное подтверждение о прошлом пополняет историю. Оно не меняет содержание ранее записанных сведений. Результат выбора на заданный момент может оказаться неизвестным даже при наличии нескольких сообщений.
