# FE-04 — отчёт реализации

Дата: 2026-11-07. Реализация согласованного поведения завершена; реальная озвучка screen reader не проверялась. Изменения оставлены unstaged, без коммита.

## Результат

HTML объявляет `lang="ru"`. `VITE_APP_NAME` задаёт одно название для вкладки, формы входа и подсказки выхода; default — `GeoService`, пробелы по краям обрезаются, пустое значение возвращает default. Название доступно в первоначальном HTML до запуска Vue и остаётся одинаковым при входе/выходе и смене экранов.

Vite нормализует значение один раз, передаёт его в безопасно экранированный title и в клиентскую константу. Название с `</title>`, `&`, кавычками и `%MODE%` остаётся обычным текстом. Production Compose передаёт настройку в Docker build; demo/dev получает environment. Для смены production-названия нужна пересборка.

## Отклонения от плана и ограничения

- Найдено дополнительное русское упоминание «Геосервис» в `LoginScreen.vue`; оно подключено к настройке согласно требованию всех UI-упоминаний. Первоначальный поиск по латинскому имени был неполным.
- Корневой `.gitignore` исключает `build/`. Два source-файла Vite явно разрешены в frontend `.gitignore`; остальные build-артефакты остаются ignored.
- Браузер использовал настоящую статику из Docker-образа и явно подменённые ответы auth API. Это проверка UI/сборки, а не backend, nginx proxy или производственная проверка авторизации. Имеющиеся component tests покрывают остальные состояния App.
- Screen reader smoke не выполнен: работающий screen reader при проверке не обнаружен, реальная озвучка не запускалась. Декларация языка проверена, правильное произношение конкретного средства не заявляется. Полное соответствие WCAG не заявляется.
- Repository-change ingest обновил существующую ноду deployment в Code_wiki: новое устойчивое знание — момент применения настройки и доставка через build args при сохранённом исключении `.env`. Отдельная agent memory не создавалась, поскольку runbook и нода сохраняют знание.
