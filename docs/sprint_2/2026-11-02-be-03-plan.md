# BE-03 · План реализации

Для исполнения по шагам использовать `superpowers:executing-plans` при работе в текущем чате или `superpowers:subagent-driven-development` при выборе делегирования.

**Цель.** Открытая подписка на слой освобождает соединение PostgreSQL до повторной проверки браузерной сессии в `connect`.

**Архитектура.** Зависимость FastAPI владеет локальной SQLAlchemy AsyncSession и возвращает готовый `WebSocketUserContext`. Погашение ticket, проверка доступа и регистрация сокета сохраняют имеющийся порядок. [Принятый дизайн](2026-11-02-be-03-design.md)

**Ограничения.** Штатный пул 5 + 5, существующие коды отказа и форма `connected`. HTTP-выдача ticket остаётся на существующей зависимости. Разовая проверка выполняется на одном процессе и отдельной PostGIS. Численный предел времени ответа не входит в приёмку. Правки остаются unstaged.
