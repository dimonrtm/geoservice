# Разделение чтения данных редактора — результат реализации

04.11.2026. [Спецификация](2026-11-03-workspace-boundaries-design.md) · [План](2026-11-03-workspace-boundaries-plan.md)

Из OpenAPI удалён `GET .../workspace`. Экран получает наряд с версией, объектами карты и связями по GET ресурса версии. Суффиксы `/change-set` и `/features/{feature_id}/baseline` открывают отдельные чтения. Каждый репозиторий обращается к своей схеме. Новых таблиц и миграций для индекса вершины не потребовалось.

В `workOrders.ts` остались назначенные наряды, их выбор, загрузка и статус. Редактор отдельно управляет чтениями, черновиком, командами и навигацией. Проверка восстановления обнаружила случай, когда временная недоступность проверки сессии во время перезапуска API останавливала повтор Save. Клиент различает смену сессии и временную невозможность подтвердить ту же сессию. При восстановлении он сохраняет исходный CommandId и тело команды.

| Проверка | Результат |
| --- | --- |
| Backend без каталога интеграционных тестов | 689 тестов прошли. 12 проверок CI и Compose пропущены из-за отсутствия файлов репозитория внутри backend-образа. Три соответствующих файла запущены отдельно с репозиторием, 14 тестов прошли. |
| Интеграция с PostgreSQL/PostGIS | 321 тест прошёл. Проверены в том числе границы доступа, скрытые изменения, отсутствующий baseline, конкуренция и атомарность Save. |
| Vitest | 492 теста прошли в 57 файлах, включая восстановление после исчерпания попыток и выбор линии при смене токена. |
| Chromium, полный M4 на отдельном Compose-стенде | Все 9 сценариев прошли. Проверены просмотр карты при недоступном ChangeSet, ручной повтор, конкурентный Save между чтениями, откат, перезапуск браузера и backend, потеря назначения, независимые наряды и IndexedDB. |
| Сборка и стиль | Production-сборка, ESLint, Ruff и проверка Git на ошибки пробелов прошли. Vite предупредил о размере основного JS-чанка. |
