# F3 — план отделения presentation

> **Исполнителю:** superpowers:executing-plans либо superpowers:subagent-driven-development согласно выбранному способу. Шаги отмечать `- [ ]`. Не выполнять git add/commit/push.

**Цель:** независимо тестируемое вычисление представления команд при сохранении реактивной сборки.

**Архитектура:** чистый domain-модуль, независимый тип фазы, один composable-адаптер существующих stores.

**Стек:** TypeScript, Vue, Pinia, Vitest.

**Спецификация:** [дизайн](2026-11-14-stage-1-design.md), раздел F3.

## Общие ограничения

Применяются все [ограничения и baseline общего плана](2026-11-14-stage-1-plan.md). Не менять условия/тексты presentation, Save handlers, focus, dialogFocus, владельцев состояния или recovery.

Подтверждённый результат без current, отличие baseline для draft/ChangeSet, смена роли и блокировка диалогом. Проверки входят в F3-1; глобальный список рисков — в общем плане.
