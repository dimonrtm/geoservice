# Этап 6 · План реализации F4

Для последовательного исполнения применяется `superpowers:executing-plans`. Для исполнения с отдельным агентом и ревью каждого шага — `superpowers:subagent-driven-development`.

**Цель.** Проверять Save/Revert, открытие вкладки, потерю доступа и подготовку к выходу без запуска Pinia, браузерного хранилища и сети. Исправить ошибку, при которой поздняя неудача загрузки прежнего пользователя блокирует Save в новой сессии.

**Устройство.** Один TypeScript-исполнитель получает состояние, хранилище, отправку, чтение и ожидание. В приложении состояние реактивно и принадлежит экземпляру Pinia. Изменения вносит исполнитель. Стек — TypeScript, Vue, Pinia, Vitest, IndexedDB и существующий браузерный стенд M4. [Принятый дизайн](2026-11-21-stage-6-f4-design.md), [исходный анализ](2026-11-21-stage-6-f4-analysis.md).

## Границы

- Публичные операции `useWorkspaceRecoveryStore`, его идентификатор `workspaceRecovery` и контракт `RecoveryHost` сохраняются.
- Первая отправка разрешена после завершения транзакции IndexedDB. Повтор использует прежние идентификатор команды, адресат, токен версии и геометрию. Известный успех при восстановлении требует только чтения.
- Сохраняются schema v2, миграция v1, два слота для фоновых запросов, интервалы 0, 2, 5, 10 и 20 секунд и отдельное согласие после потери доступа. Переназначение наряда и изменение согласования токенов F6 находятся за границей этапа.
- Пути `src/…` и команды npm ниже даны от `apps/frontend`. Новые файлы исполнителя и адаптеров располагаются рядом с существующим store в `src/stores/workspace/workspace_recovery/`.

## Пять случаев для ревью

1. Пока первая запись Save не завершилась, PUT не начался, а подготовка выхода ждёт. Ошибка записи блокирует оба действия — шаг 2.
2. После успеха Save ошибка чтения или очистки сохраняет известный результат. Количество PUT остаётся прежним — шаги 1–2.
3. Отложенный сетевой шаг теряет актуальность после смены сессии или билета чтения. Предыдущий результат не заменяет текущую карту — шаг 2.
4. Записи Марии успешно загружены, а затем приходит ошибка загрузки Алексея. Save Марии доступен. Ошибка собственной загрузки Марии блокирует Save — шаг 3.
5. Два экземпляра Pinia и повторная установка runtime в одном экземпляре. Привязки, активные попытки и изменения, видимые интерфейсу, принадлежат своему экземпляру — шаг 4.

## 1. Собрать производственные операции ввода-вывода

**Файлы.** Добавить `workspaceRecoveryIO.ts` с типами операций, `createRecoveryIO.ts` с производственной сборкой и `createRecoveryIO.test.ts`. Подключить операции в существующем `workspaceRecovery.ts`. Использовать действующие миграцию, адаптер IndexedDB, классификацию ошибок и сборщик снимка.

**Контракт.** `createRecoveryIO(): RecoveryIO` создаёт хранилище и планировщик для одного экземпляра. У `RecoveryIO` следующие операции.

- `loadActor(actorId: string): Promise<RecoveryStorageLoad>` дожидается миграции, затем вызывает `list` на том же хранилище. Для `insert`, `replace` и `remove` используются сигнатуры существующего `RecoveryStorage`, включая проверку ожидаемой ревизии.
- `send(command: PendingGeometryCommand, hadUnknown: boolean): Promise<RecoverySendResult>` возвращает `{ kind: "succeeded", result: GeometrySaveResult }` или один из существующих вариантов `SaveFailureDisposition`. Адаптер проверяет соответствие квитанции команде и использует `classifySaveFailure`. Учитывать различие первого запроса и повтора после неизвестного исхода.
- `read(context, signal, checkpoint, schedule): Promise<RecoveryReadResult>` принимает `RecoveryContext`, `AbortSignal`, `SnapshotCheckpoint` и функцию `<T>(fetch: () => Promise<T>) => Promise<T>`. Варианты результата — прочитанный `WorkspaceResponse`, потеря сессии, потеря доступа к контексту или ошибка чтения с сообщением. Действующие коды ошибок, приоритет проверки сессии и текст ошибки чтения конкретного шага берутся из текущей ветви `read`.
- `waitForRetry(delayMs, signal)` и `scheduler.run(key, signal, request)` используют текущие сигнатуры. Константа интервалов остаётся общей. В файле с контрактами для внешних типов использовать `import type`.
