Основание исходного аудита — правила `AGENTS.md` и код рабочего дерева. Это статический архитектурный аудит основных путей backend/frontend с выборочным запуском тестов, а не доказательство отсутствия всех ошибок. Сам аудит не менял реализацию. Последующая реализация F1 разрешена пользователем отдельно; её состояние и результаты находятся в verification, замечания — в [итоговом ревью F1](2026-11-17-stage-2-f1-review.md). Остальные предложения не означают разрешение начать рефакторинг.

Приоритеты обозначают порядок снижения риска, а не критичность обнаруженного инцидента. Углублённая проверка воспроизвела дефект поздних ответов в legacy polygon store; текущий App не подключает legacy editing-экран, поэтому инцидент в основном workspace не заявляется. Остальные замечания разделены на подтверждённый архитектурный долг и риски, требующие проверки сценария.

Воспроизводимые диагностические скрипты находятся в этой же папке. Они читают исходники и при указании пути сохраняют результаты анализа; файлы приложения не изменяют. Порядок запуска и ограничения описаны в углублённом анализе.
