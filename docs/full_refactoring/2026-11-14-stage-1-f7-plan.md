# F7 — план проверки List/Open и ошибок строк

> **Исполнителю:** superpowers:executing-plans либо superpowers:subagent-driven-development согласно выбранному способу. Шаги отмечать `- [ ]`. Не выполнять git add/commit/push.

**Цель:** проверять внешние ответы до изменения состояния, показывать все строки списка с ошибками полей, безопасно открывать по пригодному id.

**Архитектура:** чистые parsers → API adapters → один массив строк в workOrders → существующие список/панель. Общие ошибки протокола отделены от issues строки и от старого ProtocolError Save/recovery.

**Стек:** TypeScript, Vue, Pinia, Vitest, существующий Playwright в infra/m4.

**Спецификация:** [дизайн](2026-11-14-stage-1-design.md), разделы F7.

## Общие ограничения

Применяются все [ограничения и baseline общего плана](2026-11-14-stage-1-plan.md). Не менять серверные DTO, Save API, epoch/requestSeq, навигационные подтверждения. Не подставлять assigned вместо ошибочного статуса. При отсутствии выбранного id сохранить прежнюю очистку; при общей ошибке загрузки сохранить прежний список.

## Фокус проверки

Поздний повреждённый Open; ошибочный статус при пригодном id; несколько ошибок в строке; потеря выбранного id на фоне повреждённой строки; общая ошибка оболочки вместо пустого списка. Владельцы проверок — F7-1/2/3.
