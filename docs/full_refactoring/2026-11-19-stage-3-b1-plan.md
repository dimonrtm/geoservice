# Этап 3 · План реализации B1

Для выполнения по шагам использовать `superpowers:executing-plans` или `superpowers:subagent-driven-development` в зависимости от выбранного пользователем режима.

**Цель.** Сосредоточить порядок геометрических решений Save в доменном коде и согласовать проверку изменённой вершины с чтением рабочей версии.

**Архитектура.** Ранняя проверка цели и baseline имеет двух потребителей — подготовку кандидата и вычисление идентичности команды. После проверки токена доменная политика управляет последовательностью валидации. Адаптер материализует данные и получает вердикты PostGIS по запросу политики.

**Стек.** Python, pytest, SQLAlchemy, PostgreSQL/PostGIS. [Принятый дизайн](2026-11-19-stage-3-b1-design.md).

## Общие ограничения

- Все пути и команды ниже даны от `apps/backend`. Запускать их в штатном backend-окружении. Интеграционные сценарии требуют отдельной тестовой PostGIS БД с настроенным `DATABASE_URL`.
- Сохранить коды, сообщения, HTTP-результаты, канонизацию, оба формата fingerprint, доступ до replay, порядок prepare → проверка токена → validate, фиксацию отказов и атомарность записи.
- Сохранить публичные операции репозитория, проверки `EditGeometryScope.require/issue/consume`, принадлежность и срок действия handles. БД и SQL остаются источником пространственных фактов. Новые зависимости домена от внешних слоёв исключены архитектурным тестом.
- Изменения оставлять в рабочем дереве для проверки пользователем. B2 и изменение API находятся за границами этого плана.

## Случаи для особого внимания

| Ситуация | Ожидаемый результат | Шаг |
| --- | --- | --- |
| Чистая точка или линия с двумя вершинами | Проекция успешно читает версию. Save отклоняет редактирование | 1–2 |
| Цель с операцией deleted и отсутствующим baseline | Первым приходит FEATURE_NOT_EDITABLE | 2 |
| Доступный для fingerprint исходный снимок у нередактируемой цели | Сохраняются побайтовая совместимость fingerprint и возможность replay | 2 |
| Устаревший токен и ошибка в PreparedGeometry.rejection_code | DRAFT_VERSION_STALE до пространственных запросов | 3–4 |
| Итоговая геометрия одновременно недопустима и вне области | GEOMETRY_INVALID, в том числе при проверке политики без БД | 3 |
