## Summary

При написании и изменении кода выбирайте имена переменных, параметров и методов так, чтобы по месту использования были понятны назначение данных и действие метода. Учитывайте терминологию проекта и число объектов уже при выборе имени, до ревью пользователя.

## Context

При пакетном экспорте важно различать слой и описание его экспорта. Имя `layerExportDescriptors` в месте вызова показывает, что передаётся коллекция описаний. Единственное число в `LayerExportDescriptor` обозначает описание одного слоя.

## Actions

- Для метода подготовки коллекции `layerExportDescriptors` используйте `BuildLayerExportDescriptorsAsync`.
- Для свойства команды с DTO запроса сохраняйте принятый в проекте шаблон `StartDownloadLayersToFileDto`.
