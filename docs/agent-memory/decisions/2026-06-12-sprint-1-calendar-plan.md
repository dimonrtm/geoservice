## Summary

Спринт 1 нового Release 1 планируется на 14 календарных дней. Будние дни используются для основной разработки, выходные являются облегченными днями для интеграции, документации, проверки и резерва.

## Context

Спринт создает первый рабочий участок utility workflow: `Login -> Мои наряды -> Create/Open EditVersion -> Edit Workspace`. Выбран вертикальный подход, чтобы backend, seed, API и frontend проверялись совместно до конца спринта.

## Actions

- 2026-06-12: Пользователь подтвердил формат из 14 календарных дней.
- 2026-06-12: Подтвержден ритм `5 интенсивных + 2 облегченных + 5 интенсивных + 2 облегченных`.
- 2026-06-12: Зафиксирован план по дням, контрольные точки, scope и критерий завершения.

## Verification

План сверяется с активным design нового Release 1 и крупноуровневым планом семи спринтов. Спринт 1 заканчивается открытием изолированного workspace и не включает editing, validation, reconcile, review или post.
