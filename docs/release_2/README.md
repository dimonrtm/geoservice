# Документы Release 2

Папка содержит черновые артефакты следующего релиза GeoService. Release 2
сейчас планируется вокруг конфликта геометрии/ассоциации
(`geometry/association conflict`) и поддержки решений от последствий
(`consequence-first decision support`) перед `post`.

## Актуальные документы

- [Конфликт геометрии/ассоциации](geometry_association_conflict/README.md)
- [Контракт реализации v0.1](geometry_association_conflict/2026-06-23-implementation-contract-v0.1.md)
- [Чеклист реальной проверки с Editor/Reviewer](geometry_association_conflict/real-editor-reviewer-validation-checklist.md)

## Границы

Артефакты Release 2 являются черновыми материалами контракта/дизайна. Они не меняют
текущий объем реализации (`implementation scope`) Release 1 и не являются
production SLA.
