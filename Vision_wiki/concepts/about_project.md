# О Проекте GeoService

## Коротко

GeoService - исследовательский pet-проект для изучения алгоритмов совместного редактирования геометрии и проверки AI-first разработки сложной геоинформационной системы. Потенциальная продуктовая ценность пока является гипотезой.

## Тип Продукта

- Тип: исследовательский pet-проект / experimental prototype; возможный будущий продукт требует проверки.
- Стадия: идея / прототип.
- Primary stakeholder: [[../entities/stakeholders/dmitry_popov]].

## Проблема

- Что болит: подтвержденной внешней пользовательской боли пока нет; требуется исследовать реализацию collaborative editing геометрии.
- Почему сейчас: проект появился, когда на работе планировалась реализация подобных алгоритмов.
