# Положение устройства на момент трассировки

Положение определяют для опознанного устройства и времени расчёта. Диспетчер принимает сведения о фактическом переключении, а опубликованная схема даёт постоянные соединения. В [истории положений](../aggregates/device_position_history.md) источник и время действия связывают сообщение с конкретным положением. Время поступления показывает, когда диспетчер узнал о нём. [NET-13](../../RAW_inputs/documents/2026-11-27-field-information-answers.md#net-13).

| Что известно на время расчёта | Следующее свидетельство | Вывод диспетчера |
| --- | --- | --- |
| Подтверждённого положения нет | Поступило подтверждение поля с устройством, положением, источником и временем действия | Для расчёта на этот момент доступно подтверждённое положение. |
| Известно подтверждённое положение | Установлено более позднее переключение того же устройства | Для времени после переключения применимо новое положение, для более раннего расчёта сохраняется прежнее основание. |
| Уже установлено позднее положение | Доставлено старое подтверждение с более ранним временем действия | Оно дополняет историю и может уточнить прошлый расчёт. Текущий выбор по времени действия сохраняется. |
| Поступили взаимоисключающие сведения | Установить последовательность действий для интересующего момента невозможно | На этот момент положение неизвестно. При известной топологии диспетчер сравнивает правдоподобные варианты и просит бригаду проверить устройство. |
| Положение оставалось спорным | Бригада различила устройство и подтвердила положение на определённое время | Диспетчер пересчитывает охват на соответствующий момент. Разрешение неопределённости в настоящем само по себе не устанавливает порядок прошлых переключений. |

**Условная проверка.** При открытом устройстве расчёт охватывает ветви А и Б, при закрытом — только А. Бригада получает А как определённую расчётную часть, Б как возможную и указание проверить устройство. Если по другим пробелам в топологии даже эти варианты сравнить нельзя, охват отмечают как неустановленный. Подтверждение закрытого положения позволит исключить Б из этого расчёта. Для учёта фактического возврата услуги по А диспетчеру потребуется отдельное свидетельство. [NET-12](../../RAW_inputs/documents/2026-11-27-field-information-answers.md#net-12) · [Учёт восстановления](restoration_accounting.md).

Универсальный срок действия сообщения условная организация не установила. Давность записи сама по себе не определяет новое положение. [Основание и граница решения](../../RAW_inputs/documents/2026-11-27-field-information-answers.md#net-13).
