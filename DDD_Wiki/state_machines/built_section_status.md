# Учёт построенной части и её эксплуатационное состояние

Состояние построенной части имеет несколько независимых признаков. Подтверждение одного признака изменяет только то, что установлено его основанием.

| Что изменяется | Условие перехода | Результат для карты или трассировки |
| --- | --- | --- |
| Учёт геометрии | Часть опознана, измеренная граница выделена, объём проверен и утверждён | После публикации построенная часть видна на официальной карте. При невозможности самостоятельной проверки остаётся в рабочей версии. |
| Подключение | Проверенная правка устанавливает фактический стык | Участок получает подтверждённую связь. До этого проектная врезка не участвует в графе. |
| Ввод | Эксплуатация подтвердила ввод указанного объёма | При известных рабочих подключениях введённая часть доступна оперативной трассировке. |
| Проектное соответствие | Установлена применимая утверждённая редакция | Редактор может сравнить съёмку с требованием. При неясном ретроспективном охвате распоряжения заключение остаётся открытым. |
| Дальнейшая эксплуатация | Подтверждены объект, время и характер отключения либо вывода | Временная недоступность отличается от постоянного вывода. Присутствующее на месте оборудование сохраняется на карте и в истории. |

**Условная проверка.** Сняты два участка трубы. Оба опубликованы в измеренных границах. Для первого известны рабочие подключения и получен допуск эксплуатации. Для второго врезка показана только в проекте. Диспетчер может пройти трассировкой первый участок. Через проектную врезку второго перехода нет. Поступивший затем новый чертёж без указания на выполненные работы сохраняют для сверки. Заключение о соответствии второго участка приостанавливают до установления применимости распоряжения.
