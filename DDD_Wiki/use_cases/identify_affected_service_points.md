# Определить, каких потребителей затронуло отключение

## Повод, участники и вход

Диспетчер сообщает о нарушении обслуживания на участке в определённое время и запрашивает перечень адресатов. Группа ГИС отвечает за связь участка с точками обслуживания, диспетчер уточняет услуги и использует перечень для оперативной работы. Нужны границы известного нарушения, время, применимая схема связности и датированные отношения точек обслуживания с получателями.

## Основной ход

1. Диспетчер и картограф согласуют исходную границу, время и тип услуги. Картограф фиксирует редакцию сети и известное эксплуатационное состояние на момент события.
2. Выделяет часть сети, для которой воздействие обосновано исходными данными. Сопоставляет её с точками обслуживания и действовавшими в этот момент связями с адресатами. Проверяет общие вводы, несколько услуг по одному адресу и возможное резервное обслуживание.
3. По каждой позиции отмечает основание, известную услугу, предполагаемое воздействие и полученное подтверждение, если оно есть. Пробелы в связности, неизвестное состояние и спорные связи выносит в явный список проверки.
4. Передаёт диспетчеру датированную редакцию перечня с ограничениями. При уточнении границы или смене состояния выдаёт связанную редакцию и указывает, какие позиции добавлены, изменены или исключены.

## Альтернативы и границы

- Если неизвестна граница воздействия, картограф выдаёт только подтверждаемую часть и явно указывает, какие участки оценить пока нельзя. При отсутствии доказуемого охвата возвращает запрос на уточнение. Пустой перечень без такой оговорки нельзя трактовать как подтверждение отсутствия затронутых потребителей.
- Utility Network предоставляет связи и [историю точек обслуживания](../../Wiki/concepts/asset_service_point.md). Диспетчерская служба подтверждает фактическую потерю услуги и ведёт оповещение. Картограф передаёт только разрешённые для этой цели данные.
- Результат — список для оперативной проверки с известным охватом. Контрольная трассировка при проверке редакторской правки имеет другой результат. Допуск к работам, переключения, сообщения абонентам и восстановление услуги остаются решениями эксплуатации.

## Условия завершения

Диспетчер получает перечень на момент события и список точек с невыясненной услугой или связностью. Он может запросить уточнение конкретной позиции и сопоставить ответ с первоначальной редакцией. Полученный список достаточен для передачи в диспетчерскую работу даже при продолжающемся отключении.

## Проверка результата

На момент события один учтённый ввод обслуживал двух адресатов. К первому привязана одна услуга, для второго известно о резервном пути с неизвестным состоянием. Оба попадают в перечень с разными основаниями. После подтверждения работы резерва выпускается уточнение по второму адресату. Ни одна запись сама по себе не подтверждает отправку оповещения.
