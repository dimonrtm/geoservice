# Проверить физическое разнесение двух маршрутов

## Вопрос эксплуатации

Перед приёмкой резерва эксплуатация запрашивает заключение о конкретной паре путей. Редактор отвечает за вывод, который позволяют сделать принятые сведения о сети. Оператор услуги решает, использовать ли резерв. Понадобятся оба пути с согласованными концами, дата, уровень сравнения, исключения из охвата и основания размещения. Разрешения держателей определяют, какие сведения получатель вправе увидеть.

## Ход проверки

1. Эксплуатация уточняет, что должно быть разнесено и в каких границах. Требования «разные каналы» и «нет общего коллектора на всём пути» дают разные результаты. При неопределённом требовании редактор может сообщить известное размещение и запросить недостающий критерий.
2. Редактор прослеживает, где проходит каждый кабель в применимых редакциях и какие сооружения вмещают каналы. У каждого спорного участка видны источник и дата. Для арендованного фрагмента запрашивает у держателя относимое подтверждение либо допустимую заверенную выписку. Расстояние между условными линиями на рисунке не является измерением.
3. По данному критерию фиксирует подтверждённое разнесение, общее сооружение или неизвестность. На весь проверяемый путь вывод распространяют только в логически достаточном объёме. Одно доказанное общее сооружение опровергает требование полного разнесения по сооружениям. Для подтверждения полного разнесения надо проверить каждый включённый участок обоих путей.
4. Передаёт эксплуатации датированный ответ с редакциями, условиями, ограничениями и владельцем незакрытой части. При изменении пути, подтверждения держателя или границ запроса повторно оценивают затронутый вывод. Действительную работу услуги подтверждает эксплуатация своим испытанием.

## Пример и завершение

Между А и Б оба кабеля идут в разных каналах одного коллектора. Для запроса о каналах в выдаче есть подтверждение и подпись об общем коллекторе. Для запроса о независимости от потери одного коллектора в тех же границах получатель видит невыполненное условие. Если оба владельца прислали только отдельные схемы волокон и принадлежность каналов неизвестна, результат — ограниченный ответ с запросом недостающих сведений. Из него нельзя вывести ни совместную, ни раздельную прокладку в спорном месте.

Задача редактора завершена, когда получатель может воспроизвести вывод по каждому требуемому уровню или принял ограниченный ответ с назначенным остатком. При обнаружении ошибки учёта исправление проходит своим нарядом, проверкой и допуском. Повода изменять карту может не быть.

Внутренний аудит SingTel и разбор Bell Atlantic показывают, почему нужна отдельная проверка физического утверждения. Правило решения для двух каналов в общем коллекторе выбрала условная организация.
