# Учесть фактически построенную сеть

**Повод и входы.** Проектировщик подготовил новую трассу или изменение существующей сети. Участникам доступны проектное решение и ГИС-стандарты. Подрядчик получает согласованное задание, а владелец сети — сведения для обновления официальной модели.

1. Проектировщик согласует трассу с ГИС-стандартами и передаёт её в строительство.
2. После работ поле возвращает исполнительные сведения о фактическом положении и составе построенного участка.
3. По исполнительным сведениям обновляют авторитетную модель. Источник допускает полное и частичное обновление.

**Граница результата.** В официальной сети учтён опубликованный объём фактического исполнения. Проверяемая измеренная часть может пройти утверждение самостоятельно, даже если проектная врезка ещё требует подтверждения. Для использования построенного участка диспетчеру нужны сведения о вводе и рабочих подключениях. [Учёт геометрии, подключения и ввода](../state_machines/built_section_status.md).

**Условный пример.** Поле вернуло фактическую геометрию построенной части проектной трассы. В официальной модели можно учесть эту часть, сохраняя различие между проектом и сведениями о выполненных работах.

## Граница съёмки и ввод участка

Редактор выделяет участок, для которого известны идентичность и измеренная граница. Если этот объём самостоятельно проходит проверки, его можно утвердить и опубликовать с пометкой о неподтверждённом подключении. Проектную врезку не включают в граф по одному чертежу. Если часть нельзя выделить без нарушения правил публикации, редактор сохраняет съёмку в рабочей версии. [NET-09](../../RAW_inputs/documents/2026-11-27-field-information-answers.md#net-09).

Для эксплуатационной трассировки нужны известные рабочие подключения и подтверждение ввода от эксплуатации. При частичном вводе диспетчер видит как действующую только допущенную часть сети. Остальная измеренная геометрия может оставаться доступной на карте. [NET-10](../../RAW_inputs/documents/2026-11-27-field-information-answers.md#net-10).

## Смена редакции проекта

Для каждого построенного участка редактор связывает съёмку с выданной редакцией и применимыми утверждёнными изменениями. Если новое распоряжение явно охватывает ранее построенную часть, сверяет её по этому распоряжению. Когда охват распоряжения не установлен, сохраняет измеренный факт и оставляет заключение о соответствии открытым. Основание для ретроспективного согласования остаётся в очереди. [NET-11](../../RAW_inputs/documents/2026-11-27-field-information-answers.md#net-11).
