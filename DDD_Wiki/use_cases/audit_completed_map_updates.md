# Проверить качество серии обработанных обновлений карты

## Повод и результат

Распорядитель качества хочет узнать, какие ошибки сохраняются после обычной обработки изменений и какие работы требуется пересмотреть. Назначенный проверяющий получает состав серии за период, редакции записей и оригиналы. Результат — заключение о проверенных свойствах серии с адресными замечаниями и решением об объёме дальнейшей проверки. Закрытие отдельного наряда и одобрение конкретного пакета сохраняют свои основания.

## Ход проверки

1. Определить единицу серии и период. Записать цель: соблюдение срока, соответствие двух представлений, правильность привязки наблюдения либо содержание исходного материала. Одной серии могут соответствовать разные выборки по отдельным свойствам.
2. Зафиксировать состав серии, способ отбора и выбранные записи. При приоритетном отборе по тяжести последствий явно указать причину. Отдельно назвать недоступные основания и оставить их в остатке.
3. По выбранным записям воспроизвести исходную работу и оформить проверяемые расхождения. Ошибка кода, неверная связь записи с трубой и непригодное видео ведут к разным действиям. Для ошибки по одной записи определяют, есть ли общий источник или способ обработки, по которому следует расширить аудит.
4. Распорядителю передают охват по каждому свойству, найденные случаи, ограничения вывода и решение о дальнейших действиях. У отдельной поправки — владелец и обычный путь исправления. Право решать судьбу внешней партии определяется её собственным профилем приёмки.

## Пример и завершение

В учебной серии 60 обработанных отчётов. Соответствие номеров труб реестру проверили для всех 60. Двенадцать видео отобрали из-за ранее отмеченных серьёзных дефектов, два из них оказались неразборчивыми. Распорядитель получает 60 результатов сверки номеров, 12 результатов просмотра и два адресных замечания. Долю неразборчивых видео во всей серии эта выборка не устанавливает. Если оба пришли из одной партии записи, распорядитель может назначить дополнительный просмотр с явным основанием отбора.

Проверка завершена после передачи заключения и назначения владельцев замечаний либо согласованного остатка. Закрытие каждого исправления прослеживается отдельно. Процент отбора и период определяет задача. Условная организация не заимствовала частные нормативы операторов и не вводила новый статус публикации.
