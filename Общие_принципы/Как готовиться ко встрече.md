# Как Готовиться Ко Встрече

1. Проверить `memory/project-state.md`.
2. Просмотреть текущую модель `Wiki/DDD_Wiki`, прежние ответы и релевантный `Code_wiki`; `Vision_wiki` использовать для происхождения решений.
3. Запустить `/discover --context "..." --phase "..."`.
4. Подготовить чек-лист и до 15 смыслово новых вопросов по правилам `/discover`, без минимальной квоты. Для каждого проверить, какое ещё не принятое решение изменится после ответа. Проверки БД/кода выполнить или выделить отдельно; при исчерпании темы не дополнять список повторами.
5. После встречи сохранить сырой материал в `RAW_inputs/meetings/`.
