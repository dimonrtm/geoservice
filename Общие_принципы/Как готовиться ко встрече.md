# Как Готовиться Ко Встрече

1. Проверить `memory/project-state.md`.
2. Просмотреть `Wiki/` и `DDD_Wiki/`. Для доменных вопросов сверять происхождение решений по полю `source` и журналу `RAW_inputs/index.md`. Для технических вопросов обращаться к `Code_wiki/`.
3. Запустить `/discover` для обзора всей модели. `--wide` даёт тот же результат. Для вопросов в пределах заданной темы или фазы использовать `--context` или `--phase`.
4. По правилам `/discover` выбрать до 15 открытых вопросов о работе с инженерной сетью. Для каждого установить, какое решение в редакторе изменит ответ. Если тема исчерпана, завершить отбор.
5. После встречи сохранить сырой материал в `RAW_inputs/meetings/`.
