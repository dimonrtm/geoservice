# Как Готовиться Ко Встрече

1. Проверить `memory/project-state.md`.
2. Просмотреть текущую модель `Wiki/DDD_Wiki`, прежние ответы и релевантный `Code_wiki`; `Vision_wiki` использовать для происхождения решений.
3. Запустить `/discover` по выбранной теме или фазе. Полный обзор модели задают явно через `--wide`.
4. Взять до 15 самостоятельных вопросов, для каждого показать, как ответ изменит решение участника. Если всё уже выяснено, указать основания и завершить тему. Техническую сверку вести отдельно.
5. После встречи сохранить сырой материал в `RAW_inputs/meetings/`.
