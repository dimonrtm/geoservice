# Состояние Проекта GeoService

## Живое состояние

Начальная модель основана только на [UtilityGisEditor.md](../RAW_inputs/documents/UtilityGisEditor.md). 27.11.2026 совместный ingest [ответов](../RAW_inputs/documents/2026-11-27-field-information-answers.md) и [анализа](../RAW_inputs/documents/2026-11-27-field-information-model-analysis.md) уточнил использование полевых сведений в четырёх сценариях. Из 12 исследованных вопросов по 11 приняты решения условной организации, один решён частично. В [[DDD_Wiki/use_cases/_info|каталоге]] четыре сценария. [[Wiki/_registry/questions|Реестр вопросов]] · [[DDD_Wiki/model_health#Current Discovery Queue|Активная очередь]] · [[RAW_inputs/index|Журнал источников]].

## Требует внимания

Для четырёх технических страниц остаётся отдельная сверка с реализацией. Основания и перечень — [[Code_wiki/index#Свежие Repository-Change Знания]].

## Следующее действие

Для продолжения темы полевых сведений исследовать остаток NET-11 по эпизоду с уже построенной частью и поздним изменением проекта. Другие открытые темы — NET-02, NET-06, NET-14 и NET-15. [[Wiki/_registry/questions#Открытые|Активные вопросы]].

Спринт 3 спланирован на дни 1–14 от начала работ. Цель — через интерфейс опубликовать утверждённую часть правки по одному наряду и сохранить ошибочную связь для исправления. Первое действие по плану — проверить исходное состояние учебного фидера и определить контрольный пример, по которому пользователь различит рабочую и официальную карты.
